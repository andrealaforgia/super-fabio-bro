Drum samples from the Sonic Pi sample library
(https://github.com/sonic-pi-net/sonic-pi/tree/dev/etc/samples). They come from
freesound.org (drums by menegass, the heavy kick by Zajo) and the Sonic Pi
project placed them in the public domain under Creative Commons 0
(http://creativecommons.org/publicdomain/zero/1.0/).

`scripts/make_drum_sounds.py` cuts them into the six sounds of Fabio's drum kit.
